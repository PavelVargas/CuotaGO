Cómo empezar a usar CuotaGo

CuotaGo está pensado para que registres la operación una sola vez y el resto del sistema se actualice automáticamente.

1Registra lo que tienesUsa Inventario o Compras para introducir los artículos y sus costos.
2Crea el acuerdoSelecciona cliente, artículo, inicial, cuotas y mora si corresponde.
3Cobra sin pasos extraRegistra pagos y abonos directamente desde el acuerdo o Cobros.
4SupervisaCalendario, Notificaciones y Reportes se alimentan con lo que ya registraste.
Regla principal de CuotaGo

Si el sistema puede deducir algo de una acción que ya hiciste, no debería pedirte otro paso. Por ejemplo, al crear un acuerdo el artículo queda asignado y deja de estar disponible automáticamente.
